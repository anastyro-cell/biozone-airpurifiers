# Biozone — статическая версия сайта

Готовая статическая копия сайта: 62 страницы, без PHP и базы данных.
Все ссылки относительные, поэтому сайт работает и в корне домена, и в подпапке.

**Сайт:** https://anastyro-cell.github.io/biozone-airpurifiers/

## Структура

```
index.html            # главная
biozone-aircare.html  # страницы приборов
choice/               # разделы
news/new52/           # новости
404.html              # страница ошибки
.nojekyll             # отключает Jekyll (обязателен)
css/ js/ fonts/ i/ ill/ documents/
```

## Обновление

```bash
git add .
git commit -m "правки"
git push
```

GitHub Pages пересобирает сайт автоматически за 1–2 минуты.

## Ограничения

- `/order/` и `/cabinet/` на оригинальном сайте тоже отдавали 404
- формы заказа и админка — серверная часть, в статике её нет
- Bootstrap, jQuery, Яндекс.Метрика и Карты грузятся из интернета
